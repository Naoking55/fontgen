## ✨ 機能一覧

### 本体機能（BLOCK1-12）

#### 1. フォント編集
- TTF/OTFフォント読み込み
- 2048px × 2048px 高解像度編集
- グリフ編集（ペン、消しゴム、図形ツール）
- テキストレイヤー機能（PNG挿入）
- 選択・変形・移動機能
- アンドゥ/リドゥ（最大50履歴）

#### 2. プロジェクト管理
- `.fproj` フォルダ形式で保存
- `.fprojz` 単一ZIP形式で保存
- 異体字マッピング機能
- 編集状態の追跡

#### 3. エクスポート
- BDF形式（ビットマップフォント）
- TTF形式（TrueTypeフォント）
- PNG一括書き出し

#### 4. UI機能
- ズーム・パン機能（0.25x〜8.0x）
- グリッド表示切替
- グリフフィルタ（全て/編集済み/未編集/空白/定義済み）
- テキストプレビュー

### オプション機能（OPTION1）

#### 偏旁（部首）ツール
- 偏旁抽出ツール
- 偏旁パレット
- 偏旁プレビュー
- プロジェクトへの統合
